# Pareto.周｜AI 产品作品集

当前版本：`v1.1.0` · 内容核对日期：2026-09-15。

[访问个人网站](https://chouchoupareto.github.io/Pareto-Zhou/) · [GitHub 账号](https://github.com/ChouchouPareto)

## 场景与目的

面向 AI 产品岗位招聘者、项目合作伙伴与产品交流者，集中展示公开项目、产品判断和可验证进度。项目介绍区分原型、邀请内测和后续规划，不用模板占位或未经验证的结果描述个人经历。

## 当前进度

已完成：四个真实项目卡片、版本与公开边界说明、响应式布局、键盘焦点与菜单状态、减少动态效果偏好支持。

本次更新：Grokking恼 v0.3.1 预览、阿甘 V2.1 Beta、阿嬷公开 v0.5.1 与本地候选计划、团绘 v1.2.0 界面展示。删除示例邮箱、虚构年限和无效联系入口。光线效果仅在首屏启用，不在五个板块重复创建 WebGL 画布。

下一步：补充经授权的真实产品截图、独立案例详解和经本人确认的联系信息。尚未公开的项目不自动放入作品集。

## 本地预览

纯 HTML / CSS / JavaScript，无构建步骤：

```bash
python3 -m http.server 8000
```

访问 http://localhost:8000。GitHub Pages 发布源为 main 分支根目录。

## 发布边界

源码与公开项目链接可以发布；邀请码、密钥、用户数据、私有环境配置及内部通用手册不得提交。字体使用 Google Fonts，光线效果使用本地脚本，未实现 3D 地球。
