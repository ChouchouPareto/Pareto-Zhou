## 场景与目的

面向 AI 产品岗位招聘者、项目合作伙伴与产品交流者，集中展示公开项目、产品判断和可验证进度。项目介绍区分原型、邀请内测和后续规划，不用模板占位或未经验证的结果描述个人经历。

个人 AI 理解的核心方向是让 AI 连接真实处境，成为支持个人思考与行动的长期伙伴，保留人的选择权。Kin 承载完整愿景，其他项目在思考、学习与创作场景进行独立实践，不宣称已接入同一系统。团绘AI 在首屏、关于与重点案例中展示：普通／专业创作、项目记忆、连续母版，以及无限画布式工作空间与装修全案愿景。公开 v1.2.0 仍为无模型调用的前端展示，本地 M1 V0.2 已有独立后端与队列等切片；自由无限画布与全案尚未交付。只公开介绍，不上传本地资料。

## Kin 与马后炮

Project Kin 是长期个人 AI 伙伴方向。马后炮定位为其中的判断回看与现实反馈环节，以独立 Demo 参加中关村中客松，而不是与 Kin 并列的完整伙伴产品。比赛 Demo 展示该环节的最小闭环，V4.8 路演材料推演更完整的伙伴形态。

原版 Web 1.3.3、V2.2 本地基础工程和 V4.8 路演是不同对象的版本号。已有本地验收记录不等于正式线上发布或真实用户效果验证。授权线下设备记录、本地处理与线上交流属于目标形态，传感器接入尚未实现。本仓库只发布简介，不包含这些原始资料。

## 本地预览

纯 HTML / CSS / JavaScript，无构建步骤：

```bash
python3 -m http.server 8000
```

访问 http://localhost:8000。GitHub Pages 发布源为 main 分支根目录。
